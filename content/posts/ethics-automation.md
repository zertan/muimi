# Guardrails are features
Every automation pathway should declare what it will not do.

## Design prompts
- Write failure modes next to success cases.
- Make the exit ramps obvious and reversible.

## Stewardship beats speed
A slower rollout with transparent logging builds more trust than a fast opaque launch.
