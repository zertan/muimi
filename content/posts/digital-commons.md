# Civic-grade infrastructure
Public systems should read like clean source files—transparent and testable.

## Procurement as code review
- Ship RFPs with reproducible test cases.
- Reward vendors that keep interfaces boring.

## Trust budgets
The trust budget drops every time the interface surprises the public. Ship predictable defaults.
