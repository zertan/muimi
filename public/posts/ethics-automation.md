# Automation with a conscience

Notes on building agents that respect human boundaries and leave paper trails for every action.

## Guardrails are features

Every automation pathway should declare what it will not do, and the refusal modes should be easy to test.

## Design prompts

- Write failure modes next to success cases.
- Make the exit ramps obvious and reversible.
- Show the user the audit log before they commit.

## Stewardship beats speed

A slower rollout with transparent logging builds more trust than a fast opaque launch. Trust is the scarce resource.
